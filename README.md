# Customer_Bheaviour_Analysis
## Overview

An end-to-end **Data Analytics project** focused on transforming raw data into meaningful business insights using Python, SQL, Power BI, and data storytelling.

## Dataset

The dataset was loaded into Python and analyzed to understand its structure, patterns, and quality. It was then cleaned and prepared for further analysis.

## Tools

* **Python & Pandas** – Data loading, cleaning, and EDA
* **SQL (PostgreSQL / MySQL / SQL Server)** – Data analysis and querying
* **Power BI** – Interactive dashboard
* **Gamma** – Project presentation
* **Jupyter Notebook** – Python analysis

## Project Steps

1. **Data Loading** – Imported the dataset into Python.
2. **EDA** – Explored data types, missing values, duplicates, distributions, and trends.
3. **Data Cleaning** – Handled missing values, duplicates, inconsistencies, and incorrect data types.
4. **SQL Analysis** – Performed queries to extract key business insights.
5. **Power BI Dashboard** – Created interactive KPIs, charts, and filters.
6. **Report** – Documented the analysis, insights, and recommendations.
7. **PPT** – Created a professional project presentation using Gamma.

## Dashboard

The Power BI dashboard provides an interactive view of key **KPIs, trends, categories, and business insights**.

## Results

* Identified important trends and patterns
* Extracted actionable insights using SQL
* Created an interactive Power BI dashboard
* Summarized findings in a professional report and presentation

## Skills Demonstrated

**Python • Pandas • EDA • Data Cleaning • SQL • Power BI • Data Visualization • Business Analysis • Data Storytelling**
